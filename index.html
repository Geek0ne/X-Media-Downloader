X 会不定期更换内部接口的 query hash，换了之后抓取就会失败。 平时不用动这里，只有抓取时报「接口已变更」才需要更新。

不知道去哪儿拿新 hash？

1. 浏览器登录 x.com，打开任意用户主页
2. 按 F12 打开开发者工具，切到 Network 标签
3. 筛选框输入 UserByScreenName，点一下那条请求
4. 点 Headers，复制 Request URL
5. URL 形如 .../graphql/<hash>/UserByScreenName?variables=...
6. 把 <hash> 那段（中间那一长串）填进来

UserMedia 同理，筛选 UserMedia 即可。
